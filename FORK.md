# ThinkComposer Fork Maintenance

This repository is an independently maintained fork of
[nmarcel/ThinkComposer](https://github.com/nmarcel/ThinkComposer).

## Maintainer

- Fork maintainer: [tbm0115](https://github.com/tbm0115)
- Maintained fork: [tbm0115/ThinkComposer](https://github.com/tbm0115/ThinkComposer)
- Original upstream: [nmarcel/ThinkComposer](https://github.com/nmarcel/ThinkComposer)
- Original author: Nestor Marcel Sanchez Ahumada / Instrumind

This fork preserves the original project attribution, copyright notices, and
license terms. Changes made in this repository should be documented as fork
maintenance work so they are not confused with releases from the original
author or Instrumind.

## Support Scope

Issues, release notes, and support for this fork should use the maintained fork
repository. Do not route fork-specific support requests to the original author
unless the original author explicitly resumes that role.

## Release Policy

Fork releases should follow the existing `PublicationProcedure.txt` process
where possible. In particular:

- update the application version and release notes together
- keep installer product identity changes deliberate and documented
- regenerate the user manual from the Markdown/Pandoc sources
- provide source for released binaries in accordance with the project license
- identify release notes as fork maintenance when the change was made in this
  repository

The product name remains ThinkComposer unless a future release deliberately
chooses a stronger fork/rebrand distinction.

## Upstream Contributions

Changes may be offered back to the original upstream as focused pull requests,
but this fork's release process should not depend on upstream review or
acceptance. Small, self-contained fixes are the best candidates for upstream
submission.
