# Prototype modeling coverage

Each dimension is independent. A stored expression is not an evaluated constraint; a rectangle labeled State is not a conforming state diagram. **Native** below means the generic ThinkComposer mechanism, not a SysML semantic guarantee. Small-package persistence evidence is in `reports/native-regressions.json`; full-reference scale is a separate gap.

Survey examples exercise the narrow export subset. ModelingLab examples exercise behavior, interfaces, requirements and analysis as editable data and intentionally block their specialized export. Both exist for all four Domains. The full v1 reference import exercises additional source-shaped mappings; its opaque preservation does not upgrade these feature ratings.
